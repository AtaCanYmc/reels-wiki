Privacy Policy: reels-wiki Capture

Effective Date: November 26, 2026

1. Zero Remote Data Collection

The reels-wiki Capture browser extension runs strictly locally on your machine. It does not include analytics, telemetry, tracking pixels, advertising SDKs, or any developer-hosted backend servers.

2. What Data the Extension Accesses

  • Active Tab URL / Clicked Link URL: Accessed only when you explicitly click the extension popup button or choose Save to reels-wiki from the right-click context menu.
  • User Configuration: Your configured local server endpoint (default http://127.0.0.1:8765) and optional local Bearer token are stored solely on your device using chrome.storage.local.

3. Where Data Is Sent

When you trigger a save action, the extension sends an HTTP POST request with the selected URL exclusively to the local endpoint you configured (such as your own reels-sync serve process running on 127.0.0.1 or localhost). No data is ever transmitted to the extension author or any third party.

4. Data Sharing and Sale

We do not collect, retain, transfer, sell, or share any user data with third parties.

5. Contact

Questions or security reports can be opened on GitHub Issues.
