Saved Short-Form Videos to Obsidian Atomic Notes

A local-first pipeline that converts saved Instagram Reels, YouTube Shorts, and TikTok videos via captions, Whisper speech transcripts, and Gemini Vision OCR into deduplicated Markdown notes inside an existing 3-layer Obsidian LLM Wiki vault.

4-Stage Pipeline

  1. 01
    O(1) Media ID Gate Normalizes Instagram shortcodes, YouTube Shorts (yt_<id>), and TikTok (tt_<id>); tracks state in sources/.reels_index.json and inbox/reels-queue.jsonl.
  2. 02
    Cost-Aware Waterfall Starts with yt-dlp metadata; runs Whisper or Gemini Vision only when extracted text falls below threshold.
  3. 03
    Noise Filter & Synthesis Applies AtomicNoteSynthesis, drops low-signal clips, and repairs invalid JSON with optional fallback provider.
  4. 04
    Atomic Vault Write Enforces allowed folders, ASCII slugs, valid wikilinks, and idempotent updates to _index.md and _log.md.
Cost-Aware Extraction

Escalates to audio and vision only when text is missing

Every item moves through a 3-stage waterfall. Extracted payloads are stored in sources/reels/<shortcode>.json, and raw media files never enter the vault.

STAGE 1 / METADATA

yt-dlp Metadata & Subtitles

Calls extract_info(download=False) to fetch caption, creator, duration, upload date, and embedded subtitles without downloading video.

Stop threshold caption ≥ 150 chars
STAGE 2 / AUDIO FALLBACK

Whisper Speech-to-Text

Runs only when caption length is under min_caption_chars and no usable subtitles exist. Uses Groq whisper-large-v3-turbo or local faster-whisper.

Stop threshold transcript ≥ 40 chars
STAGE 3 / VISION OCR

Gemini 2.5 Flash Frames

Extracts 4 evenly spaced frames via ffmpeg when both caption and transcript remain short, then reads on-screen code, slides, or diagrams.

Empty guard skip before LLM

SKILL.md operational guardrails 
1. Deduplicate by 11-character shortcode before queuing.
2. Never copy video or audio files into the Obsidian vault.
3. Read _CLAUDE.md and _index.md before synthesis to match folders and tags.
4. Downgrade unmatched wikilinks to "(new note candidate) ..." plain text.
5. Preserve user edits to status and created frontmatter on forced re-runs.
Vault Enforcement

Validation guarantees before writing to disk

Model output is treated as untrusted input and normalized against your vault schema before any file is written.

Dynamic Folder & Tag Discovery

Scans _CLAUDE.md, _index.md, and note frontmatter for allowed folders and #tags. Excludes sources/ and inbox/ as note destinations.

Zero Dangling Wikilinks

Checks related_wikilinks against real vault note titles and filenames. Unknown targets are rendered as plain text (new note candidate) ....

Crash-Safe Append Queue

Writes snapshots to inbox/reels-queue.jsonl under an exclusive file lock. Stale processing entries auto-reset on the next run, and lost indexes rebuild from the queue.

Bilingual Titles & ASCII Slugs

Generates Turkish titles for Turkish Reels and technical English otherwise, while transliterating Turkish characters into clean ASCII filenames.

Zero-Download Reprocessing

Persists extracted payloads in sources/reels/<shortcode>.json so reels-sync reprocess --all can regenerate notes without touching Instagram or Whisper.

Offline Pytest Suite

Covers URL parsing, Instagram export ingestion, writer idempotency, and JSON repair retries without making network or LLM calls.

Setup

Quick Start

Requires Python 3.10 or newer and ffmpeg on your PATH for audio or frame fallbacks.

  1. 1 Install via PyPI, Homebrew, or source
    Shell 
    # PyPI
pip install reels-wiki

# Homebrew (macOS / Linux)
brew install AtaCanYmc/tap/reels-wiki

# From source
git clone https://github.com/AtaCanYmc/reels-wiki.git && cd reels-wiki && pip install -e ".[dev]"
  2. 2 Configure vault path and Instagram cookies
    config.yaml 
    cp config.example.yaml config.yaml
# Set vault_path to your Obsidian vault directory
# Under extraction:, set cookies_from_browser: chrome (or cookies_file: ~/cookies.txt)
  3. 3 Add API keys and verify configuration
    .env + verification 
    cat << 'EOF' > .env
GROQ_API_KEY=your_groq_api_key
GEMINI_API_KEY=your_gemini_api_key
EOF
