# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 0.1.x | Yes |

## Reporting a Vulnerability

Do not open public GitHub issues for security vulnerabilities, leaked credentials, or privacy issues.

Send a private report to `atacanymc@gmail.com` with:

- A description of the vulnerability and affected files.
- Steps to reproduce or a minimal proof of concept.
- Any suggested remediation if known.

Reports are acknowledged within 48 hours. Fixes are coordinated privately before public disclosure.
